# Дизайн — источник истины

**`docs/design/canvas.html` — источник истины по внешнему виду.** Это экспорт канваса Claude Design
«Лаборатория порталов» (https://claude.ai/artifact/LTfC5K5ryUv252BkNsAzTb; ссылка доступна не всем агентам,
поэтому работаем с этим экспортом). Функциональные требования — [`docs/spec.md`](../spec.md); если канвас и
спецификация расходятся по поведению, права спецификация; по виду — канвас.
[`docs/design-brief.md`](../design-brief.md) — исходный бриф, по которому канвас рисовали.

## Как читать

`canvas.html` — самораспаковывающийся бандл (7,6 МБ, шрифты внутри), читать его напрямую неудобно.
Скрипт раскладывает его на кадры:

```bash
node scripts/extract-design.mjs        # только исходники кадров
node scripts/extract-design.mjs --png  # плюс скриншоты кадров (нужен Playwright Chromium)
```

В `frames/` на каждый кадр канваса лежат два файла:

- `NN-slug.png` — как кадр выглядит (в размере кадра на канвасе). Смотреть первым.
- `NN-slug.html` — исходник кадра без шрифтов: разметка `<x-dc>` с привязками `{{…}}`, стили в
  `<helmet><style>`, логика в `<script type="text/x-dc">` (`renderVals()` — какие значения и цвета
  получаются из пропсов; `data-props` — пропсы и их значения по умолчанию). `<dc-import name="Portal" …>` —
  вставка компонента; компоненты описаны в кадрах `17`–`24` (префикс `c-`).

Файлы в `frames/` сгенерированы — не редактировать; при обновлении канваса заменить `canvas.html`
и перезапустить скрипт.

## Правила переноса в код

- Геометрию пиксель-арта (пути SVG, `viewBox`), размеры, отступы, шрифты, анимации и их `steps()`-тайминги
  переносить **дословно** из исходника кадра, а не перерисовывать по скриншоту.
- Цвета — только через `src/ui/theme/tokens.ts` (новый цвет из канваса сначала добавить туда).
  Исключение из канваса уже зафиксировано: `inkSystem` затемнён до контраста 4.5:1.
- Компоненты канваса, уже перенесённые в код (`src/ui/sprites`): `Portal` (`19-c-portal`),
  `Rune` (`20-c-rune`), `Bar` (`21-c-bar`), `Creatures` (`22-c-creatures`), `RiskTag` (плашка из
  `09-risk-language`). Использовать их, а не рисовать заново.
- **`box-sizing`.** В канвасе действует браузерное `content-box`: рамка и поля добавляются к `width`/`height`.
  В приложении `global.css` ставит всем `border-box`. Если в кадре у элемента есть размер и рамка или поля,
  но нет `box-sizing:border-box`, ставить ему `boxSizing: 'content-box'`, иначе он выйдет меньше
  (так полоска найма в HUD была на 2 px меньше).
- Готовый экран сверять со скриншотом кадра при той же ширине (1440).
