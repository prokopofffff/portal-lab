# Лаборатория порталов — спецификация

Веб-приложение для смотрителя лаборатории, где открываются магические порталы. Смотритель открывает порталы, следит за риском и решает: стабилизировать, закрыть, отправить наблюдателей изучать существ, пометить «под вопросом» или принять как есть.

Термины — по [`CONTEXT.md`](../CONTEXT.md). Визуальный стиль (пиксельная фэнтези-игра) делается отдельно в Claude Design; этот документ описывает функционал и экраны, не внешний вид.

---

## 1. Стек и поставка

- React + TypeScript + Vite, без бэкенда.
- Состояние в `localStorage` (переживает перезагрузку).
- Доменный слой — чистый TypeScript без React: состояние, команды, тик, риск, рекомендации. UI только вызывает команды и рисует состояние.
- Генератор случайных чисел передаётся в домен снаружи и инициализируется seed'ом.
- Тесты: Vitest (домен + компоненты), Playwright (e2e).
- Сдача: публичный репозиторий, деплой (Vercel / GitHub Pages), README с объяснением формулы риска и правил.
- Интерфейс на русском, код и идентификаторы на английском.

## 2. Модель

### 2.1 Мир (постоянный)

| Поле | Тип | Правило |
|---|---|---|
| Имя | строка | прилагательное + существительное, согласованы по роду; идентичность мира |
| Шифр мира | строка | вычисляется из имени (§2.4) |
| Существа | целое 0–15 | случайно при первом посещении, дальше не меняется |
| Изученные существа | целое 0…существа | общий счётчик для всех порталов в этот мир |
| Посещений | целое ≥ 1 | сколько порталов в этот мир было открыто |

Мир появляется в лаборатории при первом открытии портала в него и дальше не исчезает.

### 2.2 Портал (один проход в мир)

| Поле | Диапазон при открытии | Ограничения |
|---|---|---|
| Название | шифр мира + номер посещения (§2.4) | уникально навсегда |
| Мир назначения | случайный из словаря | ссылка на мир |
| Статус | Открыт | Открыт → Закрыт / Схлопнулся, оба конечные |
| Энергия | 10–95 | 0–100 |
| Стабильность, % | 20–100 | 0–100 |
| Время до схлопывания, мин | 30–400 | ≥ 0 |
| Наблюдатели на месте | 0 | 0–3 |
| Прогресс изучения | 0 | 0–19 наблюдателе-тиков |
| Кулдаун стабилизации | 0 | тики до следующей стабилизации |
| Пометка «Под вопросом» | нет | + необязательная заметка |
| «Принят как есть» | нет | хранит уровень риска на момент принятия |

Портал нельзя открыть повторно: новое открытие в тот же мир создаёт **новый** портал. В один мир одновременно может быть открыто несколько порталов. Закрытый или схлопнувшийся портал хранит последние метрики для карточки, но пометок и наблюдателей у него нет.

### 2.3 Лаборатория

- Время симуляции (тик = 1 минута симуляции).
- Скорость: ⏸ / ×1 / ×5 / ×20 (×1 = 1 тик в секунду). При закрытой вкладке симуляция стоит — пропущенные тики не догоняются.
- Штат наблюдателей: свободные + на месте + в пути ≤ **5**. На старте 3 свободных.
- Наём в процессе: оставшиеся тики (0, если найма нет).
- Счётчик потерянных наблюдателей.
- Журнал.

### 2.4 Имена и шифры

**Имя мира.** Прилагательное хранится в четырёх формах (м / ж / ср / мн), у существительного — род. При открытии портала выбирается случайная пара (повторы разрешены — это и есть повторное посещение мира).

**Шифр мира** — чистая функция от имени:

```
шифр мира = первая буква прилагательного + первая буква существительного + "-" + (FNV-1a-32(имя мира) mod 1000), 3 цифры
```

FNV-1a считается по UTF-16 кодам символов имени в именительном падеже («Пепельные Топи»), в JS умножение через `Math.imul`. На текущем словаре все 400 шифров уникальны — это закрепляется тестом; при изменении словаря тест укажет на коллизию.

**Название портала** = шифр мира + номер посещения: третий портал в Пепельные Топи — всегда «ПТ-420-3».

| Мир | Шифр мира | 1-й портал | 2-й портал |
|---|---|---|---|
| Пепельные Топи | ПТ-420 | ПТ-420-1 | ПТ-420-2 |
| Багровая Бездна | ББ-310 | ББ-310-1 | ББ-310-2 |
| Ледяные Чертоги | ЛЧ-244 | ЛЧ-244-1 | ЛЧ-244-2 |
| Шепчущее Зеркало | ШЗ-793 | ШЗ-793-1 | ШЗ-793-2 |
| Забытый Маяк | ЗМ-517 | ЗМ-517-1 | ЗМ-517-2 |
| Янтарный Сад | ЯС-179 | ЯС-179-1 | ЯС-179-2 |

В журнале, сводке и тостах портал пишется с миром в именительном падеже: «ПТ-420-2 (Пепельные Топи)» — без склонений.

Словарь — в [Приложении A](#приложение-a-словарь-миров).

## 3. Риск

Считается только для открытых порталов, на лету, из метрик портала.

```
нестабильность = 100 − стабильность
срочность      = время ≥ 120 ? 0 : 100 × (1 − время / 120)
балл риска     = round(0.4 · нестабильность + 0.3 · энергия + 0.3 · срочность)
```

| Балл | Уровень |
|---|---|
| 0–29 | Низкий |
| 30–54 | Средний |
| 55–74 | Высокий |
| ≥ 75 | Критический |

**Жёсткое правило:** время ≤ 10 **или** стабильность ≤ 15 → уровень Критический независимо от балла.

Существа в риск не входят: они не влияют на вероятность схлопывания, а определяют цену ошибки — поэтому учитываются в «Требуют внимания» и рекомендациях.

Карточка показывает разбивку: сколько баллов дала каждая составляющая и сработало ли жёсткое правило.

Примеры (для README и тестов):

| Стаб. | Энергия | Время | Расчёт | Итог |
|---|---|---|---|---|
| 90 | 30 | 300 | 4 + 9 + 0 = 13 | Низкий |
| 30 | 80 | 40 | 28 + 24 + 20 = 72 | Высокий |
| 12 | 20 | 300 | 35 + 6 + 0 = 41, но стаб. ≤ 15 | Критический |

Все веса, пороги и константы — в одном конфиге.

## 4. Тик

Порядок обработки на каждом тике:

1. **Наём.** Если идёт наём — счётчик −1; при 0 штат получает свободного наблюдателя (событие).
2. **Изучение** (каждый открытый портал с наблюдателями). Прогресс портала += число его наблюдателей; каждые **20** наблюдателе-тиков → +1 изученное существо **мира**. Несколько порталов в один мир пополняют общий счётчик. Когда в мире изучены все — наблюдатели **всех** открытых порталов в этот мир возвращаются свободными, их прогресс сбрасывается (событие «мир изучен»).
3. **Деградация.** Стабильность −= энергия / 200, ×0.5 если на месте есть хотя бы один наблюдатель. Время −= 1. Кулдаун стабилизации −1.
4. **Схлопывание.** Если время ≤ 0 или стабильность ≤ 0 → статус Схлопнулся. Наблюдатели на месте **потеряны** (выбывают из штата). Существа мира не меняются. Событие.
5. **Риск.** Для каждого открытого портала пересчитать уровень. Если уровень сменился — событие «уровень риска: X → Y». Если уровень стал выше, чем на момент «Принять как есть», — принятие снимается (событие).

Эвакуации нет: при критическом риске смотритель сам отзывает наблюдателей.

## 5. Действия и запреты

Каждое действие — команда домена. Результат: новое состояние + события, или **отказ** с причиной. Отказ тоже пишется в журнал. В UI недоступная кнопка приглушена и показывает причину в подсказке, но нажимается — и тогда показывается отказ.

| Действие | Эффект | Отказ, если |
|---|---|---|
| **Открыть портал** | новый портал в случайный мир со случайными метриками; если мир новый — он появляется со случайным числом существ, если известный — посещений +1 | открыто 12 порталов |
| **Стабилизировать** | стабильность +25 (≤ 100), энергия −10 (≥ 0), время +20, кулдаун 30 тиков | портал не открыт · кулдаун (осталось N тиков) · стабильность ≥ 95 |
| **Закрыть** | статус Закрыт | портал не открыт · на месте есть наблюдатели («сначала отзовите») |
| **Отправить наблюдателя** | +1 наблюдатель на месте | портал не открыт · риск критический · нечего изучать (в мире все изучены или 0 существ) · на месте уже 3 · нет свободных наблюдателей |
| **Отозвать наблюдателей** | все наблюдатели портала свободны, прогресс текущего существа сбрасывается | портал не открыт · на месте никого нет |
| **Под вопросом** (вкл / выкл) | ставит/снимает пометку, при включении — необязательная заметка | портал не открыт |
| **Принять как есть** | портал скрыт из «Требуют внимания», пока уровень риска не вырастет | портал не открыт · риск критический · уже принят |
| **Нанять наблюдателя** | через 20 тиков +1 свободный | штат (вкл. в пути) = 5 · наём уже идёт |
| **Очистить лабораторию** | всё удаляется: порталы, журнал, время; штат = 3 | — (подтверждение в диалоге) |

**Закрытие с неизученными существами.** Диалог появляется, только если в мире есть неизученные **и** это последний открытый портал в этот мир: «Это последний открытый портал в Пепельные Топи. Не изучено 6 из 9 существ — продолжить изучение можно будет, только если портал в этот мир откроется снова». Кнопки «Закрыть всё равно» / «Отмена». В журнал пишется и закрытие с числом неизученных, и отмена. Иначе закрытие без диалога.

## 6. Рекомендуемое действие

Правила по порядку, срабатывает первое. Всегда показывается с причиной.

1. Риск критический и на месте наблюдатели → **Отозвать наблюдателей**.
2. Риск критический и стабилизация доступна → **Стабилизировать**.
3. Риск критический и стабилизация недоступна → **Закрыть** (указать, сколько неизученных останется в мире).
4. Риск высокий и стабилизация доступна → **Стабилизировать**.
5. В мире есть неизученные, на месте < 3 и есть свободный наблюдатель → **Отправить наблюдателя**.
6. В мире всё изучено → **Закрыть** (безопасно).
7. Иначе → **Принять как есть**.

## 7. Сводка и «Требуют внимания»

**Сводка:** открыто N / 12 · критических · закрыто · схлопнулось · известно миров · изучено существ X из Y (по всем мирам) · наблюдатели: свободно / на месте / в пути / потеряно.

**Требуют внимания:** топ-3 открытых портала, кроме принятых как есть. Сортировка: уровень риска ↓ → время до схлопывания ↑ → неизученные существа мира ↓. У каждого — короткая причина: «критический · схлопнется через 8 мин · не изучено 6 · на месте 2 наблюдателя».

## 8. Журнал

- Запись: время симуляции («мин 143»), реальное время, портал и мир (если есть), тип — **действие / отказ / система**, текст.
- Системные события: открытие (новый мир / повторное посещение), смена уровня риска, снятие принятия, изучение существа, мир изучен, схлопывание, потеря наблюдателей, наём завершён.
- Фильтры: по типу, по порталу, по миру.
- Хранится последние 500 записей.
- **История портала** = журнал, отфильтрованный по порталу.
- **История мира** = журнал, отфильтрованный по миру: все его порталы, включая прошлые.

## 9. Экраны

Визуальная подача (пиксельный рогалик) и состав экранов — в [`docs/design-brief.md`](./design-brief.md). Здесь — функциональные требования к ним.

- **HUD** (всегда виден): время симуляции, скорость ⏸ / ×1 / ×5 / ×20, штат наблюдателей (5 слотов: свободен / на месте / в пути / пусто + счётчик потерянных), «Нанять» с прогрессом, счётчики сводки из §7, «Запечатать лабораторию» (= очистить, с подтверждением).
- **Зал лаборатории** — список открытых порталов: 12 арок = лимит открытых. Пустая арка открывает портал. Портал занимает первую свободную арку и стоит в ней до закрытия/схлопывания. Под аркой — табличка со всеми полями: название, мир, энергия, стабильность, время до схлопывания, существа мира (изучено / всего), статус, уровень и балл риска, пометки. Фильтр «Под вопросом» приглушает остальные арки.
- **«Тревожные знаки»** — «Требуют внимания» из §7, клик → карточка портала.
- **Карточка портала** — метрики, риск с разбивкой и жёстким правилом, изучение (мир, прогресс, наблюдатели, другие открытые порталы в мир), рекомендуемое действие с причиной, все действия из §5 (недоступные приглушены с причиной, но нажимаются → отказ), кулдаун стабилизации, заметка «Под вопросом», история портала. Закрытый/схлопнувшийся — только просмотр.
- **Атлас миров** — карточки известных миров: существа изучено / всего, посещений, открыто сейчас, последнее посещение; сортировка по изученности, посещениям, последнему посещению. **Страница мира**: все порталы в мир (это и архив закрытых и схлопнувшихся), история мира.
- **Книга журнала** — журнал из §8 с тремя видами записей и фильтрами по виду, порталу, миру.
- **Диалоги**: закрытие последнего портала в мир с неизученными · заметка «Под вопросом» · запечатать лабораторию.
- **Уведомления**: отказ, схлопывание, потеря наблюдателей, мир изучен, наём завершён.

## 10. Тесты

### Unit (Vitest, домен)

- Риск: примеры из §3, все пороги уровней, оба жёстких правила, границы (время 120/10, стаб. 15).
- Каждый отказ из таблицы §5 — отдельный тест, и отказ попадает в журнал.
- Стабилизация: эффект на метрики, падение балла и уровня, кулдаун 30, отказ при ≥ 95, стабилизация не делает портал вечным.
- Тик: деградация `энергия/200`, ×0.5 с наблюдателем, время −1, схлопывание по времени и по стабильности.
- Изучение: 20 наблюдателе-тиков на существо, сложение скорости, общий счётчик мира от нескольких порталов, автовозврат наблюдателей всех порталов мира при завершении, сброс прогресса при отзыве.
- Схлопывание с наблюдателями → потеря, штат уменьшился.
- Наём: 20 тиков, лимит 5 с учётом «в пути», отказ при идущем найме.
- Имена миров: все пары прилагательное × существительное согласованы по роду.
- Шифры: шифр мира детерминирован, примеры из §2.4 совпадают, все 400 шифров уникальны; название портала = шифр + номер посещения, названия не повторяются.
- Повторное посещение: новый портал, те же существа и изученные мира, новые метрики, посещений +1.
- Несколько открытых порталов в один мир одновременно разрешены.
- Принятие: исключает из «Требуют внимания», снимается при росте уровня, запрещено для критического.
- «Требуют внимания»: порядок сортировки, топ-3.
- Рекомендации: каждое правило §6.
- Закрытие: подтверждение нужно, только если в мире есть неизученные и это последний открытый портал в мир; иначе без диалога.
- События смены уровня пишутся только при смене, не на каждом тике.
- Журнал: обрезается до 500.
- Сохранение: состояние → localStorage → состояние без потерь.

### E2E (Playwright)

Запуск с `?seed=…&test=1`: фиксированный seed и тестовый хук для прокрутки тиков без ожидания.

- Пустая лаборатория показывает пустое состояние.
- Портал с критическим риском: отображение в зале, «Тревожных знаках», карточке.
- Запрещённое действие: нажатие → отказ с причиной → запись в журнале.
- Стабилизация меняет балл и уровень риска в карточке.
- Журнал после нескольких операций содержит все события в правильном порядке.
- Закрытие с неизученными: диалог, отмена, подтверждение.
- Наблюдатель: отправка, изучение, автовозврат.
- Два портала в один мир: общий прогресс изучения, закрытие одного без диалога.
- Схлопывание с наблюдателями → потеря в сводке.
- Повторное посещение мира: новый портал, страница мира показывает посещения и изученных.
- Лимит 12 открытых: все арки заняты, открытие → отказ.
- Перезагрузка страницы сохраняет состояние.
- Пауза останавливает время.

## 11. Вне рамок

- Бэкенд, аккаунты, несколько смотрителей.
- Ручной ввод параметров портала, выбор мира и демо-наборы — параметры всегда случайные.
- Самопроизвольное открытие порталов.
- Экономика и ресурсы (наём ограничен только временем и лимитом штата).
- Визуальный дизайн — делается отдельно.
