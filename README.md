# Лаборатория порталов

Пиксельная игра-симулятор для смотрителя лаборатории. Смотритель открывает порталы в случайные миры, следит за риском и решает, что делать с каждым: стабилизировать, закрыть, отправить наблюдателей изучать существ, пометить «Под вопросом» или принять как есть. Порталы деградируют сами, так что решения надо принимать вовремя.

**Приложение:** https://prokopofffff.github.io/portal-lab/

React 19 + TypeScript + Vite, без бэкенда, состояние в `localStorage`. Деплой на GitHub Pages из `main` после зелёного CI ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)).

## Запуск

Нужен Node 24. Пакетный менеджер pnpm, версия зафиксирована в `packageManager` в `package.json`.

```bash
corepack enable                        # один раз: включает pnpm нужной версии
pnpm install
pnpm dev                               # http://localhost:5173
```

Проверки:

```bash
pnpm typecheck && pnpm lint && pnpm format:check
pnpm test                              # Vitest: домен (node) и компоненты (jsdom)
pnpm exec playwright install chromium  # один раз
pnpm e2e                               # Playwright: собирает и поднимает vite preview
pnpm build                             # результат в dist/
```

## Ручная проверка

Сценарии ниже проверены на демо. Их можно пройти и локально на `pnpm dev`, заменив адрес.

**Подготовка.** Каждый сценарий начинайте в новом окне инкогнито. `?seed=N` задаёт генератор случайных чисел только на чистом старте: если в браузере уже есть сохранение, seed игнорируется. Параметр `test=1` ставит игру на паузу и добавляет в консоль команду `__lab.advance(n)`, которая проматывает n минут симуляции. Консоль открывается через DevTools (F12 или ⌥⌘J). Без консоли можно нажать «×20» в HUD и подождать: 20 минут проходят за секунду.

### 1. Критический портал: отказ и стабилизация

1. Откройте https://prokopofffff.github.io/portal-lab/?seed=3&test=1.
2. Кликните по первой пустой арке. В ней появится портал **ПП-076-1** в мир Призрачная Пещера.
3. В консоли выполните `__lab.advance(50)`. Время в HUD станет «мин 50».
4. Проверьте:
   - портал в арке горит красным;
   - в «Тревожных знаках» записка «КРИТИЧЕСКИЙ · ПП-076-1 · Призрачная Пещера» с причиной «критический · схлопнется через 7 мин · не изучено 12»;
   - в HUD «КРИТИЧЕСКИХ 1».
5. Кликните по записке. Откроется карточка портала, риск «Критический · 51».
6. Нажмите «Отправить наблюдателя». Кнопка выглядит неактивной, но нажимается. Ожидается баннер «ОТКАЗ» с причиной «Риск критический — наблюдателей не отправляют», а в истории карточки запись «Отказ «Отправить наблюдателя» ПП-076-1…».
7. Нажмите «Стабилизировать». Риск станет «Средний · 33», у стабильности появится «было 53 %, стало 78 %».
8. Наведите курсор на «Стабилизировать» ещё раз. Подсказка: «Кулдаун стабилизации — осталось 30 мин».
9. Нажмите Esc дважды: первый прячет подсказку, второй закрывает карточку.

### 2. Закрытие последнего портала в мир

Продолжение сценария 1 (или повторите его шаги 1–3).

1. Откройте карточку ПП-076-1 и нажмите «Закрыть».
2. Появится свиток «ЗАКРЫТЬ ПОСЛЕДНИЙ ПОРТАЛ?» с текстом «Не изучено 12 из 12 существ…». Фокус стоит на «Отмена».
3. Нажмите «Отмена». Свиток закроется, портал останется открытым, в истории карточки появится «Закрытие ПП-076-1 (Призрачная Пещера) отменено».
4. Снова нажмите «Закрыть», затем «Закрыть всё равно». Блок способностей исчезнет: портал закрыт.
5. Закройте карточку. В HUD «ОТКРЫТО 0 / 12», «ЗАКРЫТО 1».
6. Откройте «Книгу журнала» в доке внизу. В ней есть и отмена, и закрытие.

### 3. Наблюдатель изучает мир и возвращается сам

1. В новом окне инкогнито откройте https://prokopofffff.github.io/portal-lab/?seed=12&test=1.
2. Кликните по пустой арке. Появится портал **ЗС-226-1** в мир Забытое Святилище, в котором 2 существа.
3. Откройте карточку портала. Изучено «0 из 2».
4. Нажмите «Отправить наблюдателя». В карточке «наблюдателей: 1», в HUD один наблюдатель «на месте» и два «свободен».
5. `__lab.advance(20)` → изучено «1 из 2».
6. `__lab.advance(20)` → изучено «2 из 2». Появится баннер «МИР ИЗУЧЕН», наблюдатель вернётся сам: в HUD снова три «свободен», в карточке «наблюдателей нет».
7. «Отправить наблюдателя» теперь недоступна: изучать нечего. В HUD «ИЗУЧЕНО СУЩЕСТВ 2 / 2».

### 4. Два портала в один мир

1. В новом окне инкогнито откройте https://prokopofffff.github.io/portal-lab/?seed=878&test=1.
2. Кликните по двум пустым аркам. Оба портала ведут в Призрачное Ущелье (15 существ): **ПУ-953-1** и **ПУ-953-2**. В HUD «МИРОВ 1».
3. В карточке ПУ-953-1 есть пометка «ещё 1 открытый портал в этот мир: ПУ-953-2». Отправьте туда наблюдателя.
4. Закройте карточку, откройте ПУ-953-2 и тоже отправьте наблюдателя.
5. `__lab.advance(20)`. В обеих карточках изучено «2 из 15»: счётчик общий на мир.
6. В карточке ПУ-953-1 нажмите «Отозвать наблюдателей», затем «Закрыть». Портал закроется без свитка-подтверждения, потому что в мир открыт ещё один портал.
7. В HUD «ОТКРЫТО 1 / 12», «ЗАКРЫТО 1». Наблюдатель ПУ-953-2 остаётся на месте.
8. Откройте «Атлас миров» → «Призрачное Ущелье» → «Страница мира →». В сводке «Посещений 2», «Открыто сейчас 1», в списке оба портала.

### 5. Схлопывание с наблюдателем и сохранение после перезагрузки

1. В новом окне инкогнито откройте https://prokopofffff.github.io/portal-lab/?seed=3&test=1.
2. Откройте портал ПП-076-1 в первой арке и отправьте в него наблюдателя. Закройте карточку.
3. `__lab.advance(57)`. Время портала 57 минут, так что он схлопнется.
4. Проверьте:
   - баннеры «ПОРТАЛ СХЛОПНУЛСЯ» и «НАБЛЮДАТЕЛИ ПОТЕРЯНЫ»;
   - в HUD «СХЛОПНУЛОСЬ 1», «ОТКРЫТО 0 / 12»;
   - наблюдателей два «свободен» и «×1 потеряно»;
   - «ИЗУЧЕНО СУЩЕСТВ 2 / 12»: наблюдатель успел изучить двоих.
5. Перезагрузите страницу (F5). Время «мин 57», счётчики HUD те же.
6. Откройте «Книгу журнала». Семь записей по порядку: открытие (мин 0), отправка наблюдателя (мин 0), два изученных существа (мин 20 и 40), «уровень риска: средний → критический» (мин 47), «схлопнулся: время вышло» и «потеряно наблюдателей — 1» (мин 57).
7. Нажмите «Запечатать лабораторию» в доке. Появится свиток «ЗАПЕЧАТАТЬ ЛАБОРАТОРИЮ?»; нажмите «Запечатать». Время снова «мин 0», все счётчики HUD на нуле, в штате 3 свободных наблюдателя.

## Правила и решения

Правила лежат в [`docs/spec.md`](docs/spec.md), термины в [`CONTEXT.md`](CONTEXT.md), все числа баланса в [`src/domain/config.ts`](src/domain/config.ts). Внешний вид взят из экспорта канваса в [`docs/design/`](docs/design/README.md).

Риск считается из трёх метрик: `round(0,4 · (100 − стабильность) + 0,3 · энергия + 0,3 · срочность)`, где срочность растёт от 0 до 100 за последние 120 минут жизни портала. Пороги: 0–29 низкий, 30–54 средний, 55–74 высокий, от 75 критический. Если до схлопывания осталось ≤ 10 минут или стабильность ≤ 15, уровень критический при любом балле. Существа в риск не входят: они не ускоряют схлопывание, а только определяют, что потеряется вместе с порталом.

Что спецификация не задаёт и как это решено:

- Скорость после перезагрузки сбрасывается на ×1, остальное сохраняется.
- Пока вкладка скрыта, время стоит, пропущенное не догоняется.
- Сохранение версионировано (ключ `portal-lab`, `SAVE_VERSION` 2). Повреждённое или старое сохранение заменяется новой игрой, ошибка записи игру не роняет.
- Генератор случайных чисел (mulberry32) сохраняется вместе с игрой, поэтому после перезагрузки последовательность продолжается.
- Журнал хранит последние 500 записей.
- Тринадцатый портал из интерфейса не открыть: при 12 открытых пустых арок нет. Отказ домена на этот случай покрыт unit-тестом.
- Роутера нет, после перезагрузки открывается зал.
- Баннеры въезжают плавно, а не ступенями, как в канвасе, и не исчезают, пока под курсором или в фокусе.
- `src/domain` не зависит от React и браузерных API, `Math.random` там запрещён линтером.

## AI Worklog

Полная версия на экране «AI Worklog» (четвёртая вкладка дока), данные в [`src/ui/worklog/worklog.ts`](src/ui/worklog/worklog.ts).

- **Инструменты:** Claude Code (Opus 5.5, в субагентах Sonnet 5.5 и Haiku 4.5), Claude Design, Conductor, skills superpowers, mattpocock-skills и frontend-design, трекер beads.
- **Время:** 13–15 октября 2026, около двух дней.
- **Токены:** ≈ 314 млн, 96 % из них чтение кэша, вывод 1,6 млн (`node scripts/count-tokens.mjs`). Расход Claude Design не учтён.
- **Кто что делал:** человек ставил задачи, отвечал на вопросы по ТЗ, рисовал канвас, проверял деплой и сливал PR. Код, тесты и ревью писал AI, руками код не правился.
- **Где AI ошибся:** пропустил «мир назначения» в ТЗ, считал, что порталы открываются сами, предлагал типовой дашборд, store терял события тика, вёрстка ломалась на промежуточных ширинах, HUD проверялся только на macOS, и e2e упали на Linux в CI.
- **Проверка:** 869 unit-тестов, 65 e2e на 1440 и 390 px, CI на каждый PR.

```
e2e/          сценарии Playwright
docs/         spec.md, design-brief.md, design/ (экспорт канваса)
scripts/      extract-design.mjs, count-tokens.mjs
```
